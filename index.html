Five tools for language documentation, one shared file

A free, offline-capable toolkit for writing texts, interlinear glossing, building a lexicon, corpus analysis, and vocabulary/sentence elicitation — all in one HTML file, sharing one project folder.

Open OWL Suite How it works
Features
✍️

Writer

Write or import texts, add per-sentence and whole-text translations in any number of languages, and find & replace across the corpus.

🔤

Glosser

Interlinear morpheme glossing with a suggester that learns from your own confirmed glosses — allomorphs, reduplication, and infixes included.

📚

Lexicon

The project dictionary: morphemes, glosses, allomorphs, part of speech, semantic domains, and one-click promotion from the corpus.

📊

Analyze

Frequency lists, KWIC concordance, multi-domain sentence search, collocation stats, and a phonology tab with segment inventory and IPA chart.

🎙

Elicit

Vocabulary elicitation from prompt-list domains, plus questionnaire-driven sentence elicitation for TAM and narrative sequences.

🔗

One shared format

Every tool reads and writes the same plain-text files and JSON sidecars. No import, no export — an edit in one tool is simply there in another.

✈️

Works offline

A single HTML file plus one shared JS file. No installation, no server, no account, no internet required once downloaded.

📁

Your data stays yours

Everything is saved as plain text and JSON directly to a folder you choose on your own computer — nothing is uploaded anywhere.

How to use

Download both owl_suite.html and suite-core.js into the same folder — OWL Suite needs both files together to run.

Open owl_suite.html in Chrome or Edge (see browser support below).

Choose a folder for your project. Everything you save lives there as plain text and JSON.

Switch tools using the tabs across the top — Writer, Glosser, Lexicon, Analyze, and Elicit all share the one folder you picked.

Start in Writer, gloss it in Glosser, curate morphemes in Lexicon, and search or check phonology in Analyze — or collect new vocabulary and sentences in Elicit.

Your folder is portable — copy it, back it up, or move it to another computer. OWL Suite reconnects automatically the next time you open the same folder.

Browser support: OWL Suite runs entirely in your browser with no server, but it depends on the File System Access API to read and write your project folder directly.
