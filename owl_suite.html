Lexicon

Open your project folder. The lexicon lives in a single plain-text lexicon.jsonl file — one entry per line, readable anywhere. If the folder has glossed texts, morphemes you've used that aren't in the lexicon yet appear as candidates, one click from becoming entries.

Analyze

Open the same project folder Writer, Glosser, and Lexicon use. Analyze reads — word and morpheme frequency, concordance/KWIC, and per-text distribution across every .txt and .gloss.json file there — and, on the Phonology tab only, writes the segment/allophone/vowel-consonant/phoneme-feature settings that tab uses. Nothing else here is ever edited or saved.

Phoneme features

Assign any features you want per phoneme — place, manner, voicing, orality, height, backness, frontness, roundness, tense, or anything else. Used by the IPA-style chart to group phonemes into natural classes.
